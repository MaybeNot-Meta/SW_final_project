# myfo — 경험을 포트폴리오로 연결하는 웹서비스

**myfo**는 사용자가 자신의 경험을 발견하고 기록한 뒤, 직무 역량을 확인하고 포트폴리오를 구성하도록 돕는 웹서비스입니다. 경험이 부족한 사용자에게는 새로운 활동을 탐색할 수 있도록 안내하고, 경험이 있지만 정리가 어려운 사용자에게는 경험 기록과 STAR 구조화를 지원합니다.

> 대학 오픈소스 SW 기말 팀 프로젝트입니다. 현재 기능 통합과 전수 테스트를 진행 중이며, 공개 URL 배포는 준비 중입니다.

## 주요 기능

| 영역 | 기능 |
| --- | --- |
| 온보딩 | 닉네임 및 사용자 유형 선택, 유형 1 관심 태그 설정, 기본 정보·학력 선택 입력 |
| 메인 홈 | 오늘의 질문, 추천 태그, 최근 경험 기록, 기능별 바로가기 |
| 경험 기록 | 경험 꺼내기, STAR·KPT·자유 기록, 검색·필터, 기록 수정·삭제, 캘린더·성장 기록 |
| 직무 연결 | 경험·관심 태그 기반 직무 추천, 역량 분석 차트, 부족 역량 확인, 목표 직무 저장 |
| 포트폴리오 | 프로젝트 생성, 경험 연결, STAR 정리, 문장 변환, 슬라이드 구성, PDF·PPTX 출력 |
| 경험 채우기 | 추천 활동·공고 탐색, 검색·필터·정렬, 공고 상세, 스크랩·진행 상태, 참여 기록 |
| 마이페이지 | 사용자 정보·학력·관심 태그 수정, 데이터 관리 |

각 기능은 가능한 범위에서 공통 저장 구조를 사용합니다. 일부 추천 공고와 직무 정보는 프로젝트에 포함된 **예시 데이터**를 사용하므로 실시간 채용·공모전 정보와 다를 수 있습니다.

## 실행 방법

별도의 Node.js 설치나 빌드 명령 없이 실행할 수 있는 **HTML / CSS / JavaScript 정적 웹 프로젝트**입니다.

1. 이 저장소를 복제하거나 ZIP으로 다운로드합니다.
2. Visual Studio Code에서 프로젝트 폴더를 엽니다.
3. VS Code **Live Server** 확장 프로그램을 설치합니다.
4. 루트 폴더의 `index.html`을 열고 **Open with Live Server**를 실행합니다.
5. 표시된 브라우저에서 myfo를 이용합니다.

```bash
git clone -b integration/step7 https://github.com/MaybeNot-Meta/SW_final_project.git
cd SW_final_project
```

> 데이터는 기본적으로 브라우저의 `localStorage`에 저장됩니다. 따라서 다른 브라우저·기기·시크릿 창과 자동 동기화되지 않습니다. 브라우저 저장 데이터를 지우면 기록이 사라질 수 있으므로 테스트 중 초기화에 주의하세요.

## 기술 스택 및 오픈소스

**개발 환경:** HTML5, CSS3, JavaScript, VS Code, Live Server, Git / GitHub  
**저장 방식:** Web Storage API (`localStorage`)

프로젝트 코드에서 불러오는 주요 라이브러리는 다음과 같습니다.

| 라이브러리 | 활용 목적 |
| --- | --- |
| Pretendard | 공통 한글 웹 폰트 |
| Lucide | 아이콘 |
| Day.js | 날짜 표시·처리 |
| SweetAlert2 | 사용자 확인 및 알림창 |
| Chart.js | 직무 역량 데이터 시각화 |
| Fuse.js | 경험 기록·활동 검색 |
| SortableJS | 포트폴리오 항목 정렬 |
| FullCalendar | 경험 기록 캘린더 |
| Cal-Heatmap / D3.js | 성장 활동 히트맵 |
| html2pdf.js | 포트폴리오 PDF 출력 |
| PptxGenJS | 포트폴리오 PowerPoint 출력 |

라이브러리 상당수는 CDN으로 제공되므로, 해당 기능을 사용하려면 인터넷 연결이 필요할 수 있습니다. 상세 버전과 라이선스는 각 라이브러리의 배포 정보를 기준으로 확인해야 합니다.

```text
├── portfolio/               # 포트폴리오 작성·내보내기

├── .gitignore
└── README.md
```
