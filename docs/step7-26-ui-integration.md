# STEP 7-26 · myfo 전체 UI/UX 일괄 통합

## 변경 방향
- 기존 4개 기능 파트(경험 기록, 직무 연결, 포트폴리오, 경험 채우기)와 홈·마이페이지의 색상/글꼴/폭/버튼/카드 스타일을 `common/unified-ui.css`에서 일괄 관리합니다.
- 기존 `common/tokens.css`의 파란색·연보라색 토큰을 각 모듈의 별도 색상 변수에 연결합니다.
- 페이지별 탭/폼/캘린더/차트/스크랩/내보내기 이벤트와 기존 id, data-* 및 저장소 구조는 유지했습니다.

## 용어 수정
- 경험 기록: 이미 적용된 `나의 경험을 기록하다`를 유지. 보조 표기 `TEMPLATE` → `작성 방식`, `MY RECORDS` → `나의 기록`.
- 경험 채우기: 잘못 공통화된 `내 성장 여정`을 실제 위치인 `modules/fill/index.html`과 `js/fill-header.js`에서 정정. 시작 화면은 `새로운 경험을 찾아서` + `경험 채우기`, 추천 화면은 `경험 채우기` + `맞춤 추천`.
- 직무 연결: 제목 위에 `경험에서 진로로` 표시.

## 기존 링크·데이터 참조 오류 정정
- `mypage.html`의 존재하지 않는 `job-match.html` 링크를 `modules/job/index.html`로 수정했습니다.
- 마이페이지에서 목표 직무 ID 대신 공통 직무 데이터의 한글 이름을 보여줍니다.
- `portfolio/export.html`의 존재하지 않는 `../data/jobs.js` 대신 `../modules/job/data/jobs.js`를 불러오고, 포트폴리오에서 이 공통 직무 목록(6개)을 우선 사용합니다. 기존 독립 실행용 폴백은 유지합니다.
- 첫 페이지 HTML의 잘못된 독립 백틱 문자 1개를 제거했습니다.

## 자동 검증 결과
- 13개 서비스 페이지 DOM/콘솔 확인: 인라인 로컬 리소스와 외부 라이브러리 모의 객체를 사용하는 제한된 브라우저 테스트에서 자바스크립트 예외 없음.
- 모든 기존 HTML ID 유지, 모든 내부 상대경로 대상 존재 확인.
- `node --check`: 전 JS 파일 문법 검사 통과.
- CSS 토큰/규칙 파싱 검사 통과.
- PC(1400px), 태블릿(980px), 모바일(375px): 주요 5개 페이지 가로 스크롤 넘침 없음, 모바일 공통 메뉴 열림/닫힘 확인.
- 경험 채우기 검색 및 스크랩 전환, 경험 기록 탭 전환, 6개 직무 목록, 포트폴리오 목표 직무 자동 선택, 마이페이지 직무명 표시 검증.

## 개발자 주의
- 자동 테스트에서는 외부 CDN(Lucide, Chart.js, FullCalendar, Sortable, PptxGenJS 등)을 모의 처리했습니다. 실제 Live Server 환경에서 기록 CRUD·차트·캘린더·스크랩 지속성·포트폴리오 PPT/PDF 내보내기 최종 회귀 검증이 필요합니다.
- 개인 데이터는 로컬 브라우저 localStorage에 남아 있으며 이번 변경은 저장 함수 또는 키를 수정하지 않았습니다.
- 원본 테스트용 `step7-preview.html`과 원본 이력성 SHA 파일은 의도적으로 변경하지 않았습니다.
