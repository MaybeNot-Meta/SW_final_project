
# SW_final_project

## 프로젝트 소개

자신의 경험을 발견하고 정리하여 포트폴리오로 연결하는
자기계발 포트폴리오 작성 웹서비스입니다.

포트폴리오를 처음 준비하거나, 경험은 있지만 이를
효과적으로 정리하기 어려운 사용자를 대상으로 합니다.

## 프로젝트 목표

- 사용자 상태에 따른 맞춤형 시작 과정 제공
- 경험 기록 및 역량 관리
- 경험과 관련 직무 연결
- 경험을 활용한 포트폴리오 작성
- 부족한 역량을 채우기 위한 활동 추천

## 주요 기능

| 기능 | 설명 |
|------|------|
| 온보딩 | 사용자 유형 및 관심 태그 설정 |
| 메인 홈 | 사용자 상태와 주요 기능 요약 |
| 경험 기록 | 활동 및 경험 작성·관리 |
| 직무 연결 | 경험 기반 직무 매칭 |
| 포트폴리오 | 프로젝트 및 STAR 경험 정리 |
| 경험 채우기 | 역량에 맞는 활동 추천 |
| 마이페이지 | 사용자 정보 수정 및 데이터 관리 |

## 기술 스택

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git / GitHub
- GitHub Pages (배포 예정)

### 오픈소스 활용 계획

- Pretendard: 공통 웹 폰트
- Lucide: UI 아이콘
- Day.js: 날짜 관리
- SweetAlert2: 사용자 확인창
- Chart.js: 데이터 시각화
- Fuse.js: 검색
- SortableJS: 드래그 앤 드롭
- html2pdf.js: PDF 내보내기

라이브러리는 해당 기능 구현 단계에서 적용합니다.

## 개발 환경 및 실행 방법

Visual Studio Code를 사용하여 개발합니다.

HTML 화면 구현 후 VS Code의 Live Server로
웹사이트를 실행할 예정입니다.

현재는 공통 CSS 파일만 작성된 초기 개발 단계입니다.

## 협업 방식

공통 파일 및 데이터 형식을 기준으로 최종 통합합니다.

GitHub를 활용하여 작업 내용과 변경 이력을 관리합니다.
