# STEP 7 · 화면·기존 기능을 유지하는 연동 오류 4건 수정

원본: `SW_final_project_clean.zip` (2026-11-26 수신)

## 변경 내역

1. **온보딩 유형 2** (`js/home.js`): 기존 사용자 정보 입력·저장 화면과 데이터 검증은 그대로 유지하고, 사용자 정보 저장 후 `modules/record/index.html?tab=extract`로 이동합니다. 유형 1의 관심 태그 선택과 홈 대시보드 흐름은 유지합니다.
2. **경험 꺼내기 → 직무 연결** (`modules/record/script.js`): 3개 이상의 답변을 작성해 기존 **직무 매칭** 버튼을 누르면 공통 `records` 저장소에 `source: "경험꺼내기"`로 각각 저장하고 직무 연결 페이지로 이동합니다. 공통 `TAGS` 목록에 있는 역량 태그를 답변 내용의 키워드로 추출하며, 키워드가 없으면 분류별 기본 태그를 넣습니다. 이 태그는 **자동 추정 초안**으로, 기록 목록에서 '기록 편집'을 눌러 실제 경험에 맞게 수정하는 것을 권장합니다. 똑같은 답변을 다시 제출할 때는 중복 기록을 추가하지 않으며, 이미 저장된 경험은 화면을 재방문해도 표시됩니다.
3. **기록 목록 → 프로젝트 묶기** (`modules/record/script.js`, `portfolio/js/projects.js`): 선택한 기록의 ID로 프로젝트를 공통 `projects` 저장소에 즉시 저장하고 `portfolio/index.html?project=...`로 이동해 새 프로젝트를 강조합니다. 기록 본문과 기존 프로젝트는 유지하며, 이미 다른 프로젝트에 묶인 기록을 재선택하면 중복 프로젝트 생성을 막습니다. 포트폴리오 화면에서 프로젝트 제목은 자유롭게 변경할 수 있습니다.
4. **부족 역량 분석 → STAR 정리** (`modules/job/job-connection.js`, `modules/job/index.html`): 기존 모듈의 `selfdev:navigate` 이벤트를 통합 사이트의 실제 페이지로 연결합니다. 강점 항목에 표시된 근거 경험 중 첫 기록의 ID를 전달해 `portfolio/star.html?record=...`로 이동합니다. 연결된 프로젝트가 있으면 기존 프로젝트를 사용하고, 없는 경우 STAR 모듈의 **기존 동작대로** 해당 기록으로 새 프로젝트를 만듭니다.

## 변경하지 않은 영역

- **CSS 전체 / 기존 화면 구성 / 요소 ID / 네비게이션·공통 헤더 / 공통 저장 API·키**
- 마이페이지, 경험 채우기, 포트폴리오 내보내기, 차트, 캘린더 등 그 외 페이지
- 원본 `index.html`과 `portfolio/index.html`의 HTML·CSS

## 자동 검사

```bash
node tests/regression-fixes.cjs
```

검사 범위: 유형 1/2 온보딩 분기, 경험 3건 저장·태그 집계·중복 방지, 프로젝트 생성·기록 보존·중복 방지, STAR의 근거 기록 연결 및 프로젝트 선택, 공통 기록 수정/삭제. 별도로 전체 JavaScript 문법과 로컬 HTML 파일 참조 경로를 검사했습니다.

**제한:** 브라우저 실행이 제한된 환경에서 작성했으므로, 전체 UI와 외부 CDN을 포함한 실제 Live Server 수동 검증은 완료되지 않았습니다.

## Live Server 최종 수동 회귀 테스트

- 기존 데이터를 백업해 두고 테스트 전용 브라우저 프로필이나 시크릿 창으로 시작합니다. **마이페이지 초기화는 기존 실제 데이터가 있는 브라우저에서 실행하지 않습니다.**
- 유형 1: 닉네임 → 유형 1 → 관심 태그 2~3개 → 프로필 입력/건너뛰기 → 홈 대시보드 → 메인 기능·헤더·마이페이지 정상 여부.
- 유형 2: 닉네임 → 유형 2 → 프로필 입력/건너뛰기 → 경험 꺼내기 탭 자동 진입.
- 경험 꺼내기: 서로 다른 경험 3개 작성 → **직무 매칭** 버튼 활성화 → 클릭 → 직무 연결 화면에서 경험 3개·보유 역량 표시 → 브라우저 뒤로 가기/새로고침 후 기록 중복 생성 없는지 확인.
- 경험 기록: 태그 포함 기록 새로 작성, 검색·필터·정렬, 상세, 수정, 삭제, 캘린더·스트릭 확인. 기존 STAR/KPT/자유 기록 각 1건 편집 후 저장 확인.
- 기록 목록: 미묶음 기록 2개 선택 → 프로젝트 묶기 → 포트폴리오 프로젝트 생성/선택한 2개 기록/대표 태그 확인 → 제목 수정·저장·재접속. 기록 원본은 남아 있어야 합니다.
- 직무 연결: 직무 매칭/분석/직무 카드, 목표 직무 저장, 강점 STAR 버튼 → STAR 화면 열림 → 선택한 근거 기록이 해당 프로젝트에 포함돼 있는지 확인 → STAR 답변 저장.
- 다른 기능: 마이페이지 정보 수정, 경험 채우기 추천·스크랩·참여, 포트폴리오 프로젝트 추가·드래그·STAR·내보내기, 공통 헤더의 모든 메뉴 정상 동작 확인.

**주의:** 로컬 저장소를 쓰는 사이트이므로 실제 사용 중인 기록을 잃지 않도록 기존 데이터를 먼저 보호하세요. `node`가 설치되지 않아도 Live Server 실행 자체에는 Node.js가 필요하지 않습니다.
